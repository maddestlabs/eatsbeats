Eatscript Engine API & DSP Reference

Core Governing Principle
Eatsbeats uses Eatscript, a custom, pure-Dart, Pythonic audio DSP and scripting language. There is NO Lua engine or runtime in this codebase. Real-time audio evaluation is sample-by-sample and block-by-block with zero garbage collection allocations.

High-Level Architecture

Eatscript scripts execute inside an isolated EatScriptContext managed by the DAW. Each track channel, insert effect, or pipeline step can host an Eatscript:

  • Track Audio Synthesis: Generate polyphonic waveforms, sample-accurate frequency modulation, and physical models.
  • Insert & Master FX: Process incoming stereo audio with delay lines, choruses, saturators, and bit-crushers.
  • Skeuomorphic GUI Panels: Return declarative UI trees complete with 6-zone hardware knobs, nixie tubes, and live oscilloscopes.
  • MIDI Pipeline & Transforms: Algorithmic Euclidean rhythm generators, chord-followers, and humanization.

Quick Example: Virtual Analog Synth

import math

def init():
    return {
        "Cutoff": eat.param("Cutoff", 100.0, 12000.0, 1800.0, unit="Hz"),
        "Resonance": eat.param("Resonance", 0.5, 10.0, 2.5),
        "EnvMod": eat.param("EnvMod", 0.0, 1.0, 0.6),
        "Decay": eat.param("Decay", 0.05, 2.0, 0.4, unit="s"),
    }

def gui():
    return {
        "panel": {
            "title": "ANALOG LEAD",
            "subtitle": "Virtual Analog Eatscript Synth",
            "background": "dark",
            "accent": "#00FFE0",
            "knobStyle": "chrome",
            "layout": [
                {
                    "type": "row",
                    "children": [
                        {"type": "knob", "param": "Cutoff", "label": "CUTOFF"},
                        {"type": "knob", "param": "Resonance", "label": "RESO"},
                        {"type": "knob", "param": "EnvMod", "label": "ENV"},
                        {"type": "knob", "param": "Decay", "label": "DECAY"},
                    ]
                }
            ]
        }
    }

def process(time, freq, note, params, targetNote=0, isSlide=False, isAccent=False):
    cutoff = params.get("Cutoff", 1800.0)
    decay = params.get("Decay", 0.4)
    
    # Oscillator: Sawtooth wave
    phase = time * freq
    osc = 2.0 * (phase - math.floor(phase)) - 1.0
    
    # Envelope
    env = math.exp(-time / max(0.01, decay))
    
    # Output saturation
    return math.tanh(osc * env * 1.2)

01. Eatscript Syntax & Lifecycle

Eatscript uses 4-space indentation, Python functions (def), and hash comments (#). Standard math operations are available via import math.

Script Archetypes & Signatures

ArchetypeProcess SignatureTarget Domain
Synth Voicedef process(time, freq, note, params, targetNote=0, isSlide=False, isAccent=False)Instrument Tracks
Audio FXdef process(input_l, input_r, params)Insert & Master FX
MIDI Pipelinedef process(notes, time_ctx)Track Note Pre-processing
Automationdef process(time, value, params)LFOs & Parameter Envelopes

Native Dispatch Delegation

Scripts can delegate sample computation directly to pre-compiled native Dart DSP engines by declaring top-level flags:

# High-Performance Transistor Ladder TB-303
Eats303 = True
JC303 = True

# Hardware Bitcrusher & Sample-Rate Reduction
Bitcrusher = True

02. Parameter System & Variance Engine

Parameters are registered in the def init(): hook using eat.param():

eat.param(
    "Cutoff",             # Parameter name / key
    min=20.0,             # Minimum numeric value
    max=20000.0,          # Maximum numeric value
    default=1500.0,       # Initial default value
    step=1.0,             # Granularity increment (0.0 for continuous)
    options=[],           # List of string options for switches
    allow_variance=True,  # Whether track variance humanizes this param
    variance_scale=1.0,   # Sensitivity multiplier
)

The Analog Variance Engine

Simulates thermal analog drift and component tolerances across synth voices:

  • eat.variance(): Reads the active track's master variance slider (0.0 to 1.0).
  • eat.vary_param(name, params, scale=0.1): Returns variance-adjusted parameter values.
  • eat.vary(val, scale=0.1): Micro-drift helper for raw floating-point values.
  • eat.ignore_variance(name): Explicitly exempts a parameter from variance modulation.

05. MIDI & Music Theory API

Manipulate note buffers and musical structures inside eat:

  • eat.add_note(pitch, start=0.0, duration=1.0, velocity=0.85): Appends a note.
  • eat.scale(root="C", type="minor"): Returns valid in-scale pitch arrays.
  • eat.scale_conform(pitch, root=0, is_minor=False): Quantizes pitch to active scale.
  • eat.snap_to_chord(pitch, chord="Am7", mode="chord"): Snaps pitch to chord tones.
  • eat.euclidean(step, steps=16, pulses=4, shift=0): Bjorklund Euclidean rhythms.
  • eat.arpeggiate(notes, rate=1.0, octaves=2, pattern="up"): Generates arpeggios.
  • eat.chord_follow(notes, mode="chord"): Follows DAW song chord progression.

06. DAW & Macro API

Automate the host workstation using eat.daw or project:

# Adjust Project Tempo & Key
eat.daw.set_tempo(140.0)
eat.daw.set_key("E Minor")

# Manage Tracks
bass = eat.daw.add_track("Sub Bass", type="bass")
bass.set_volume(0.9)
bass.set_param("Cutoff", 600.0)

# Create Clip & Automate Parameter
clip = bass.create_clip(start_bar=0, length_bars=4)
bass.add_automation_point("Cutoff", step=0.0, val=200.0, easing="exponential")
bass.add_automation_point("Cutoff", step=64.0, val=2400.0, easing="linear")

# Offline Audio Export
eat.daw.render_audio(filename="render.wav", bars=16)
