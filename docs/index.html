Eatscript Engine API & DSP Reference

Core Governing Principle
Eatsbeats uses Eatscript, a custom, pure-Dart, Pythonic audio DSP and scripting language. There is NO Lua engine or runtime in this codebase. Real-time audio evaluation is sample-by-sample and block-by-block with zero garbage collection allocations on the critical rendering path.

High-Level Architecture

Eatscript scripts execute inside an isolated EatScriptContext managed by the DAW. Each track channel, insert effect, or pipeline step can host an Eatscript:

  • Track Audio Synthesis: Generate polyphonic waveforms, sample-accurate frequency modulation, and physical waveguide models.
  • Insert & Master FX: Process incoming stereo audio with delay lines, choruses, saturators, and bit-crushers.
  • Skeuomorphic GUI Panels: Return declarative UI trees complete with 6-zone hardware knobs, nixie tubes, LCDs, and live oscilloscopes.
  • MIDI Pipeline & Transforms: Algorithmic Euclidean rhythm generators, chord-followers, and humanization.
  • DAW Macro Orchestration: Script headlessly via eat.daw or project to create tracks, clips, automation points, and render audio/video.

Quick Example: Virtual Analog Synth

A complete, self-contained instrument defining parameters, a skeuomorphic control panel, and an audio process hook:

import math

def init():
    return {
        "Cutoff": eat.param("Cutoff", 100.0, 12000.0, 1800.0, unit="Hz"),
        "Resonance": eat.param("Resonance", 0.5, 10.0, 2.5),
        "EnvMod": eat.param("EnvMod", 0.0, 1.0, 0.6),
        "Decay": eat.param("Decay", 0.05, 2.0, 0.4, unit="s"),
    }

def gui():
    return {
        "panel": {
            "title": "ANALOG LEAD",
            "subtitle": "Virtual Analog Eatscript Synth",
            "background": "dark",
            "accent": "#FF8C00",
            "knobStyle": "chromeFluted",
            "layout": [
                {
                    "type": "row",
                    "children": [
                        {"type": "knob", "param": "Cutoff", "label": "CUTOFF"},
                        {"type": "knob", "param": "Resonance", "label": "RESO"},
                        {"type": "knob", "param": "EnvMod", "label": "ENV"},
                        {"type": "knob", "param": "Decay", "label": "DECAY"},
                    ]
                }
            ]
        }
    }

def process(time, freq, note, params, targetNote=0, isSlide=False, isAccent=False):
    cutoff = params.get("Cutoff", 1800.0)
    decay = params.get("Decay", 0.4)
    
    # Oscillator: Sawtooth wave
    phase = time * freq
    osc = 2.0 * (phase - math.floor(phase)) - 1.0
    
    # Envelope
    env = math.exp(-time / max(0.01, decay))
    
    # Output saturation
    return math.tanh(osc * env * 1.2)

High-Performance Native Dispatch Directives

Scripts can delegate sample computation directly to pre-compiled native Dart DSP engines using either:

  1. Header Directive (Recommended): # @engine: <id>
  2. Programmatic Binding: eat.use_engine("<id>") in def init():
  3. Legacy Boolean Flags: Eats303 = True, Bitcrusher = True, Analog808Kick = True
# Explicit Native Binding
# @engine: tb303

def init():
    eat.use_engine("tb303")
    eat.param("Cutoff", 200.0, 8000.0, 1200.0, unit="Hz")
    eat.param("Resonance", 0.0, 10.0, 6.0)
    eat.param("EnvMod", 0.0, 1.0, 0.7)
    eat.param("Decay", 0.1, 2.0, 0.4, unit="s")

02. Parameter System & Variance Engine

Parameters are registered in def init(): using eat.param():

eat.param(
    "Cutoff",             # Parameter name / key
    min=20.0,             # Minimum numeric value
    max=20000.0,          # Maximum numeric value
    default=1500.0,       # Initial default value
    step=1.0,             # Granularity increment (0.0 for continuous)
    unit="Hz",            # Display unit (Hz, ms, s, dB, %, etc.)
    options=[],           # List of string options for discrete switches
    allow_variance=True,  # Whether track variance humanizes this param
    variance_scale=1.0,   # Sensitivity multiplier
)

Positional & Keyword Overloads

Eatscript accepts flexible calling conventions:

  • eat.param("Cutoff", 20.0, 20000.0, 1500.0) (min, max, default)
  • eat.param("Cutoff", 1500.0, 20.0, 20000.0) (default, min, max)
  • eat.param("Waveform", 0.0, 3.0, 0.0, step=1.0, options=["SAW", "SQR", "TRI", "SIN"])

7. Modular Graph Primitives (`eat.node.*`)

In Approach C, modular racks compile directly from Pythonic def graph(): definitions into zero-allocation, native C/Dart GraphNode trees:

def graph():
    vco = eat.node.osc(wave="saw", detune=2.5)
    sub = eat.node.sub(octave=-1, level=0.4)
    vcf = eat.node.moog(in_sig=vco + sub, cutoff="Cutoff", reso="Reso")
    env = eat.node.adsr(attack="Attack", decay="Decay", sustain="Sustain", release="Release")
    sat = eat.node.saturate(in_sig=vcf, drive="Drive")

05. MIDI & Music Theory API

Manipulate note buffers and musical structures inside eat:

Note Buffer Operations

  • eat.add_note(pitch, start=0.0, duration=1.0, velocity=0.85): Appends a note.
  • eat.get_notes(): Returns current note list as standard dictionaries.
  • eat.clear_notes(): Empties current note buffer.

Scales & Chord Conformance

  • eat.scale(root="C", type="minor"): Returns valid in-scale pitch arrays across the keyboard (major, minor, dorian, mixolydian, blues, pentatonic).
  • eat.scale_conform(pitch, root=0, is_minor=False): Quantizes pitch to active song scale.
  • eat.scale_snap(notes, key=0, scale=0): Snaps all notes in a list to specified key and mode.
  • eat.snap_to_chord(pitch, chord="Am7", mode="chord"): Snaps pitch to chord tones, chord scale, or root/bass.
  • eat.chord_follow(notes, mode="chord"): Follows DAW song chord progression in real time.

Rhythm & Arpeggiation

  • eat.euclidean(step, steps=16, pulses=4, shift=0): Step test for Bjorklund Euclidean rhythms.
  • eat.euclidean(pulses, steps): Overload returning a complete binary rhythm list: e.g. eat.euclidean(4, 16).
  • eat.arpeggiate(notes, rate=1.0, octaves=2, pattern="up", gate=0.85, swing=0.0): Arpeggiator.
  • eat.chord_arp(notes, rate=1.0, octaves=1, pattern="up"): Chord-aware arpeggiator.
  • eat.humanize(notes, timing=0.02, velocity=0.08): Micro-timing jitter and velocity variations.
  • eat.transpose(notes, semitones=0): Pitch transpositions.

Randomness Helpers

eat.random_int(min=0, max=10), eat.random_float(min=0.0, max=1.0), eat.random_choice(list).

1. Virtual Analog Poly Synth (Instrument)

# @id: va_lead
import math

def init():
    return {
        "Waveform": eat.param("Waveform", 0.0, 1.0, 0.0, step=1.0, options=["SAW", "SQR"], allow_variance=False),
        "Cutoff": eat.param("Cutoff", 40.0, 14000.0, 2200.0, unit="Hz"),
        "Resonance": eat.param("Resonance", 0.5, 12.0, 4.0),
        "Attack": eat.param("Attack", 0.002, 1.0, 0.01, unit="s"),
        "Decay": eat.param("Decay", 0.05, 3.0, 0.45, unit="s"),
        "Drive": eat.param("Drive", 0.0, 1.0, 0.2),
    }

def gui():
    return {
        "panel": {
            "title": "VINTAGE POLY SYNTH",
            "subtitle": "Virtual Analog 24dB Ladder Synth",
            "background": "dark",
            "accent": "#FF8C00",
            "knobStyle": "chromeFluted",
            "layout": [
                {
                    "type": "row",
                    "children": [
                        {"type": "switch", "param": "Waveform", "label": "WAVE", "options": ["SAW", "SQR"]},
                        {"type": "knob", "param": "Cutoff", "label": "CUTOFF"},
                        {"type": "knob", "param": "Resonance", "label": "RESO"},
                        {"type": "knob", "param": "Attack", "label": "ATTACK"},
                        {"type": "knob", "param": "Decay", "label": "DECAY"},
                        {"type": "knob", "param": "Drive", "label": "DRIVE"},
                    ]
                }
            ]
        }
    }

def process(time, freq, note, params, targetNote=0, isSlide=False, isAccent=False):
    wave = params.get("Waveform", 0.0)
    decay = params.get("Decay", 0.45)
    attack = params.get("Attack", 0.01)
    drive = params.get("Drive", 0.2)
    
    phase = time * freq
    normPhase = phase - math.floor(phase)
    saw = 2.0 * normPhase - 1.0
    sqr = 0.85 if normPhase < 0.5 else -0.85
    osc = (1.0 - wave) * saw + wave * sqr
    
    env = (1.0 - math.exp(-time / max(0.001, attack))) * math.exp(-time / max(0.01, decay))
    out = osc * env
    if drive > 0.01:
        out = math.tanh(out * (1.0 + drive * 4.0))
    return out

3. Lo-Fi Stereo Bitcrusher (Audio FX)

# @id: lofi_crusher
import math

def init():
    return {
        "Bits": eat.param("Bits", 2.0, 16.0, 8.0, step=1.0, allow_variance=False),
        "Downsample": eat.param("Downsample", 1.0, 32.0, 2.0, step=1.0, allow_variance=False),
        "Mix": eat.param("Mix", 0.0, 1.0, 0.8),
    }

def process(input_l, input_r, params):
    bits = params.get("Bits", 8.0)
    mix = params.get("Mix", 0.8)
    
    levels = 2.0 ** bits
    crushed_l = math.floor(input_l * levels + 0.5) / levels
    crushed_r = math.floor(input_r * levels + 0.5) / levels
    
    out_l = input_l * (1.0 - mix) + crushed_l * mix
    out_r = input_r * (1.0 - mix) + crushed_r * mix
    return [out_l, out_r]

AI Agent Skill & Grounding

Antigravity AI Agent Skill
The official Eatscript skill is installed at .agents/skills/eatscript/SKILL.md. When Gemini, Claude, or any AI pair programmer works on Eatsbeats, this skill automatically supplies the grammar rules, parameter definitions, and DSP catalogs.

Strict AI Generation Rules

  • NEVER write Lua: Eatsbeats has NO Lua runtime. Always write Eatscript (Pythonic syntax with def, 4-space indentation, # comments).
  • Parameter Registration: Always declare continuous parameters with min, max, and default in def init():.
  • Zero Audio Allocations: Inside def process():, never create objects, arrays, or allocate dynamic memory. Perform pure mathematical evaluations.
  • Safe Clipping: Always pass audio outputs through math.tanh() or clamp within [-1.0, 1.0] to avoid harsh digital clipping.
